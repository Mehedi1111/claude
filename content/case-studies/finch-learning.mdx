Finch Learning builds adaptive curriculum software for secondary schools. When their iOS app was ready for App Store submission in March 2025, their engineering team hit a wall they hadn't anticipated: the App Store rejected their icon.

Not for policy reasons. For technical file quality.

## The Problem

Finch's lead designer had created their mark in Ideogram — a clean, geometric bird silhouette that tested well with educators. The SVG export from Ideogram looked correct in Figma and in the browser. But the engineering team's audit told a different story.

<Callout type="warning" title="What Was Inside the 22KB SVG">
847 anchor points describing a shape that needed 34. Inline style attributes on every single path element, making CSS theming impossible. Group IDs automatically generated as `g4821`, `g4822`, `g4823` — meaningless to any developer. A viewBox set to an arbitrary `0 0 1080 1080` with no responsive configuration. And the App Store icon export — a PNG derived from this SVG at 1024×1024 — was failing Apple's icon quality check.
</Callout>

The App Store rejection cited "icon does not meet image quality guidelines." The underlying cause: the SVG's redundant paths were causing rendering artefacts at certain export sizes that the App Store's automated review process flagged.

The performance issue was separate but compounding. The 22KB SVG was being inlined in the React app's header component — loaded on every page, parsed on every render. Google's Lighthouse was docking performance points and, with it, organic search rankings the team was counting on.

## The Reconstruction

We rebuilt the SVG from scratch, using the Ideogram export purely as a visual reference.

| Metric | Original | Rebuilt |
|--------|----------|---------|
| File size | 22.1KB | 1.8KB |
| Anchor points | 847 | 34 |
| Style approach | Inline on every element | CSS custom properties |
| Dark mode support | Requires duplicate file | 3 lines of CSS |
| Animation readiness | Not possible | Layer-ready |
| App Store exports | Failing review | Approved |

The rebuild preserved every visual characteristic of the original mark. The bird silhouette proportions, the internal negative space, the optical weight — all matched. The difference was in the technical layer: how the file was structured, not what it displayed.

## The React Component

Beyond the optimised SVG file, we delivered a typed React component:

```tsx
interface FinchLogoProps {
  size?: number | string;
  color?: string;
  className?: string;
}

export const FinchLogo: React.FC<FinchLogoProps> = ({
  size = 48,
  color = 'currentColor',
  className,
}) => { /* clean, 34-point SVG */ }
```

The component defaults to `currentColor` — meaning it automatically inherits the CSS text colour of its container. Dark mode requires no JavaScript: the CSS `color` property change cascades into the SVG automatically.

## The App Store Icon Set

We exported the complete Apple App Store icon set from the rebuilt SVG: all twelve required sizes from 20×20 to 1024×1024. Each export was pixel-perfect at its target size — no aliasing, no rendering artefacts. The App Store submission was approved on the first attempt.
