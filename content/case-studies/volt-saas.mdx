Volt SaaS builds infrastructure tooling for B2B data pipelines. Their engineering team is methodical about performance — which is why the state of their logo SVG was frustrating them.

The logo had been exported from a design tool, converted once through an online SVG optimizer, and then embedded in their React codebase. The result was a file that technically worked but was a production engineering nightmare.

## The Problem

<Callout type="warning" title="What Their SVG Actually Contained">
14.2KB for a simple geometric mark. 847 anchor points where 18 were needed. Inline `style` attributes on every path, making CSS theming impossible. Group IDs like `Layer_0_1_2_3` that revealed nothing about the structure.
</Callout>

Their frontend team had tried three times to implement dark mode logo switching. Each attempt required either JavaScript DOM manipulation or maintaining two entirely separate SVG files. Neither was acceptable.

The animation team wanted to build an entrance animation for the logo in their marketing site. After analysing the SVG structure, they gave up — the paths were too fragmented to animate meaningfully.

## The Audit

We ran a full audit against the five criteria for production-ready SVGs:

| Criterion | Current State | Target |
|-----------|--------------|--------|
| File size | 14.2KB | &lt;3KB |
| Anchor point count | 847 | &lt;25 |
| Semantic structure | None | Named layers by element |
| CSS theming support | None (inline styles) | CSS custom properties |
| Animation readiness | Not possible | Layer-based animation scaffold |

## The Reconstruction

The SVG was rebuilt from scratch, using the existing file only as a visual reference.

<BeforeAfter
  beforeLabel="14.2KB Export"
  afterLabel="2.1KB Rebuild"
  beforeCaption="847 anchor points, inline styles, no structure"
  afterCaption="18 anchor points, CSS variables, animation-ready"
/>

The rebuild process:

1. **Geometry clean reconstruction** — Rebuilt the primary mark with mathematically minimal anchor points
2. **Semantic layer structure** — Named groups: `logo-mark`, `logo-wordmark`, `logo-tagline`
3. **CSS variable integration** — All colours defined as `var(--logo-primary, #0a0a0a)` for easy theming
4. **Animation scaffold** — Each animatable element on its own layer with clean IDs
5. **ViewBox optimisation** — Configured for responsive use at any container size

## The React Component

Beyond the SVG file, we delivered a typed React component:

```tsx
interface LogoProps {
  size?: number | string;
  color?: string;
  className?: string;
  animated?: boolean;
}

export const VoltLogo: React.FC<LogoProps> = ({
  size = 120,
  color = 'currentColor',
  className,
  animated = false,
}) => { /* ... */ }
```

The component accepts colour as a prop (defaulting to `currentColor` for automatic CSS inheritance), size as either a number or CSS string, and an `animated` prop that triggers the entrance animation when true.
