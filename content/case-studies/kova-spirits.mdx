Kova Spirits founder Niamh O'Brien had spent three months developing her craft gin range. The botanical recipe was locked. The distillery was contracted. The label design — a striking Art Deco frame with layered botanical illustrations, generated in Midjourney after forty-seven iterations — was exactly what she'd envisioned.

Then the packaging printer rejected the file.

## The Rejections

**Rejection 1** (label printer, offset lithography): *"File resolution insufficient for print at label dimensions. Minimum 300 DPI at final size required. Current effective resolution: 72 DPI equivalent. Please supply vector artwork."*

**Rejection 2** (follow-up submission, same vendor): *"Gold colour values supplied as RGB. Gold foil process requires Pantone specification or CMYK equivalent for proofing. Colour result cannot be guaranteed from current file."*

Niamh had asked a freelancer to "make it a vector" after the first rejection. The freelancer had run the Midjourney PNG through Adobe Illustrator's auto-trace. The second rejection proved that an auto-traced file is not a vectorised file — it's a raster image disguised as a vector.

<Callout type="warning" title="What Auto-Trace Actually Produces">
Auto-trace converts pixels to paths — but it converts every pixel. A simple botanical illustration auto-traces to 3,000–8,000 anchor points. True vectorisation of the same mark needs 200–400. The difference determines whether a print vendor's RIP processor accepts or rejects the file.
</Callout>

## The Audit

We opened both files — the original Midjourney PNG and the auto-traced SVG — and ran a complete technical audit.

| Issue | Auto-Traced File | Our Reconstruction |
|-------|-----------------|-------------------|
| Anchor point count | 6,847 | 312 |
| Open paths | 23 | 0 |
| Colour mode | RGB only | RGB + CMYK + Pantone |
| Gold foil separation | Not present | Pantone 871 C isolated |
| Scalability | Degraded above 200% | Infinite |
| RIP compatibility | Failed | Passed |

The botanical elements — four distinct plant species, an oval frame, and a wordmark — required individual path reconstruction. Each leaf, stem, and botanical detail was rebuilt using Bézier curves matched to the visual character of the original Midjourney output.

## The Process

Kova's mark presented a specific technical challenge: the gold foil elements needed to be isolated as a separate layer for spot colour printing. This is not something that can be achieved from a raster source or an auto-traced file — it requires deliberate structural decisions at the path level.

We rebuilt the mark in three distinct structural layers:

1. **Black ink layer** — the frame, typography, and supporting botanical linework
2. **Gold foil layer** — the botanical highlights, rule lines, and frame detail (Pantone 871 C)
3. **Background layer** — clear for transparent label stock, white for kraft paper alternative

Both layers were tested against the vendor's colour profile for the specific label stock before delivery.
