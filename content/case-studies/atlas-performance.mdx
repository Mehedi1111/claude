James Okafor had been training clients for nine years before he opened his first gym. When the second and third locations followed within eighteen months, he had a Midjourney-generated mark he loved — a bold, angular form with strong geometric energy. The problem was that nobody in his vendor network could use it.

The sign company said no. The uniform supplier said no. The web developer said the SVG export was "a mess." Three locations opening on fixed dates, and the brand couldn't be applied to anything.

## The Vendor Responses

Atlas Performance received the same core message from three different production suppliers:

**Signage company** (vinyl, 6ft wide): *"We need a vector file. This is a raster image. We cannot guarantee quality at this output size."*

**Embroidery supplier** (uniform logos): *"Too many colours and too much detail for embroidery. We need a simplified 2-colour version and a path file, not a picture."*

**Web developer**: *"The SVG you've given me is just a raster image wrapped in SVG tags. It's not actually a vector. I can't make this responsive or animate it."*

Each rejection came from a legitimate technical limitation. Each was solvable with properly structured files. The Midjourney PNG was never going to work — but the mark it depicted was perfectly suitable for all three applications.

<Callout type="note" title="Three Different Production Requirements">
Signage needs infinite scalability and CMYK colour accuracy. Embroidery needs simplified geometry, defined stitch paths, and typically a maximum of 2–3 thread colours. Web needs a clean SVG with responsive viewBox, no inline styles, and dark/light variants. One raster file cannot serve all three — but one properly structured master vector can.
</Callout>

## The Reconstruction

We began with a full geometric analysis of the Midjourney mark: the proportions of the angular form, the relationship between the lettermarks and the icon, and the weight hierarchy across elements.

The master vector was rebuilt with:
- 4-colour system (process black, deep navy, athletic grey, white)
- Mathematical proportions on a 12-unit grid
- Clean paths at every component level for future editing

## Specialist Output Variants

From the master vector, we produced three application-specific variants:

**Signage variant:** CMYK-certified colour values, spot colour separations, file structured at 1:10 scale for the sign company's large-format workflow. Tested at 6ft equivalent and confirmed zero quality degradation.

**Embroidery variant:** 2-colour simplification (process black + white only), minimum stitch detail removed, paths structured for DST/PES embroidery format conversion. The supplier's digitiser could work directly from this vector.

**Web SVG variant:** Clean semantic structure, responsive viewBox, CSS custom property colour theming, dark variant (white mark on dark backgrounds), light variant (dark mark on white). Delivered as both standalone SVG and React component.
