Roam Collective curates monthly adventure boxes for travellers — field guides, navigation tools, local provisions from a new destination each month. They'd been building their online presence for eight months when their launch date was finally set: a Product Hunt submission aligned with a redesigned website.

The website's hero section was designed around an animated version of their compass-inspired mark. Two weeks before launch, their developer delivered difficult news: the SVG was impossible to animate.

## The Structure Problem

Roam's mark — a minimal compass rose with a wordmark — had been refined from a Stable Diffusion output. A designer had exported it from Figma as SVG. It looked perfect in the browser. But when the developer opened the file to begin the animation work, what they found was not what either party expected.

<Callout type="warning" title="What the SVG Actually Contained">
Group nesting seven levels deep. Every path in the file labelled `path1` through `path847`. Inline fill and stroke attributes on every single element. The compass needle — the one element the developer needed to rotate independently — was merged at path level with the inner ring. There was no way to select individual elements programmatically. Animation was structurally impossible without a full rebuild.
</Callout>

The developer's response was accurate: you can't animate what you can't select.

## The Reconstruction

We rebuilt the SVG from scratch in four clearly defined structural groups:

1. `#compass-outer-ring` — the static outer frame
2. `#compass-directions` — N/S/E/W indicators (scale in on entrance)
3. `#compass-needle` — the rotating needle element (continuous or entrance rotation)
4. `#wordmark` — the logotype (fade + slide in on entrance)

Each group was given semantic IDs, no inline styles, and CSS custom property colour variables. The rebuild took the file from 18KB to 2.3KB — a reduction achieved by rebuilding paths with minimal anchor points rather than compressing or removing content.

| Metric | Original | Rebuilt |
|--------|----------|---------|
| File size | 18.2KB | 2.3KB |
| Anchor points | 1,247 | 89 |
| Nesting depth | 7 levels | 2 levels |
| Semantic IDs | None | 4 named groups |
| Animation readiness | Impossible | Layer-ready |

## The Animation Sequence

Once the rebuilt SVG was integrated, we delivered the full CSS animation sequence as a standalone stylesheet:

- **0–400ms:** Outer ring fades in with subtle scale from 0.92 to 1
- **200–600ms:** Cardinal points cascade in with staggered opacity
- **400ms:** Compass needle sweeps from 45° to 0° with spring easing
- **600–900ms:** Wordmark slides up 12px and fades to full opacity

The sequence required no JavaScript — pure CSS `@keyframes`, timed to create a cohesive entrance that felt intentional, not decorative.
