What's included in a branding package depends entirely on who you ask — and that's the problem.

Walk into a conversation with ten different designers and agencies and you'll get ten different definitions. Some will call a logo and a JPEG a "complete brand package." Others will include 60 pages of brand guidelines and a full messaging framework in the same description.

This guide breaks down what a professional branding package actually contains — so you can evaluate what you're being offered before you pay for it.

---

## The Core: What Every Branding Package Should Include

These are non-negotiables. If any of these are missing, the package is incomplete regardless of what the agency calls it.

### Logo Files — All Formats

The logo itself, delivered in every format you'll need:

**Vector files** — AI (Adobe Illustrator source file), EPS (for print production), SVG (for web). These are the files that scale to any size. Without them, you can't use your logo professionally in print, signage, or at large scale.

**Raster files** — PNG with transparent background (for use on any coloured surface), JPEG (for documents). Multiple sizes.

**Print-ready PDF** — a portable version that printers, embroidery suppliers, and other vendors can open without needing Adobe software.

One format is not enough. One size is not enough. [What files a designer should deliver](/blog/what-files-should-a-designer-deliver) covers the complete list and what each one is actually used for.

### Logo Colour Variants

Your logo in at least three versions:

- **Full colour** — primary version for light backgrounds
- **Reversed/white** — for dark backgrounds, coloured surfaces, dark merchandise
- **Single colour/mono** — for embossing, engraving, embroidery, and black-and-white print

Each variant should exist in every file format. A delivery that only includes the full-colour version is incomplete.

### Colour Palette

Your brand colours with exact values for every medium:

- **HEX** — for web and digital use
- **RGB** — for screen use and digital design tools
- **CMYK** — for print reproduction
- **Pantone** — for brand-critical print like packaging and signage where exact colour reproduction matters

A designer who gives you "your brand colour is #1A3C5E" has given you a web colour. They haven't given you a colour palette. If you ever go to a printer and they ask for your CMYK or Pantone values, you'll realise what's missing.

### Typography

Your brand fonts — what they are, where they're used, and in what hierarchy.

Typically: a primary font for headlines and display use, a secondary font for body text and supporting copy. Some brands have a third accent font.

The typography documentation should specify which weights to use (Bold, Regular, Light), how headings are sized relative to body text, and any specific typographic rules (all-caps headlines, letterspacing adjustments, etc.).

It should also specify the web-safe fallback font if the brand font isn't available in a certain context.

### Brand Guidelines

This is what separates a professional brand delivery from a logo delivery.

Brand guidelines (also called a style guide or brand book) document the rules for using the brand consistently. A complete brand guidelines document covers:

**Logo usage** — correct placement, minimum size, clear space (the minimum breathing room around the logo), and a "don't do this" section showing incorrect usage.

**Colour palette** — all values, approved combinations, which colour goes with which, what to avoid.

**Typography** — font usage hierarchy, approved pairings, text formatting rules.

**Imagery style** — if applicable, the photographic or illustrative approach the brand uses.

**Tone of voice basics** — at minimum, a description of how the brand sounds in written communications.

Without guidelines, every time someone other than the original designer applies your brand — a new employee, a freelancer, a social media manager — they'll make guesses. Those guesses accumulate into inconsistency. [What brand guidelines should include](/blog/brand-guidelines-what-they-include) covers the full contents of a professional style guide.

## What Better Packages Add

These elements aren't in every branding package, but they should be in any comprehensive one.

### Brand Strategy Document

Before the visual design, a strategy-first agency will produce a written brand strategy. This typically covers:

- Brand positioning (who you're for, what you stand for, how you're different)
- Target audience definition
- Competitive landscape overview
- Brand personality and tone of voice
- Key messages

This document is what makes the visual decisions intentional rather than aesthetic. It's the difference between a logo that looks good and a logo that communicates the right thing to the right people.

### Application Design

Showing how the brand looks in real contexts:

- Business cards
- Email signatures
- Letterhead
- Social media profile assets (profile photo, cover image)
- Presentation template (PowerPoint or Google Slides)
- Proposal template

Not every branding package includes these — they're often available as add-ons. But they're worth asking about, because seeing the brand applied to real materials confirms that it works outside the logo presentation and catches any issues before the guidelines are finalised.

### Naming

If your business name is still to be decided, some agencies offer naming as part of a brand package — generating candidate names, checking trademark availability, testing for pronunciation and international considerations.

Most agencies treat this as a separate service. If naming is part of what you need, confirm whether the agency handles it before you brief.

## What Cheap Packages Are Usually Missing

Below a certain price point, something gets cut. Usually multiple things.

**No source files.** The logo is delivered as a PNG or JPEG only. You own an image. You don't own a logo.

**No brand guidelines.** The colour codes are mentioned in an email. The font is named but not specified. Nobody's documented anything. The moment someone other than the original designer touches the brand, consistency is gone.

**One concept, no process.** One direction is presented, take it or leave it. No discovery, no strategy, no alternatives.

**No colour variants.** Full colour only. When you need a white version for a dark background, you're improvising.

**No file ownership.** Some cheap services retain ownership of source files and license the logo to you. You're renting, not owning.

These aren't always obvious from the listing or the pitch. Ask directly: what formats do I receive? Do I get the source files? Is a style guide included? What's the revision process?

The questions to ask before signing are covered in detail in [questions to ask before hiring a branding agency](/blog/questions-to-ask-before-hiring-a-branding-agency). Many of them apply equally to independent designers.

## How to Evaluate What You're Being Offered

When you receive a quote for a branding package, ask the agency to list what's included — specifically. Not "a complete brand identity" — but what files, what variants, what documents, what revision rounds.

Then check it against this list:

| Deliverable | In Your Package? |
|---|---|
| Vector source files (AI/EPS) | |
| SVG for web | |
| PNG (transparent, multiple sizes) | |
| PDF print-ready | |
| Full colour, reversed, mono variants | |
| Colour palette with HEX, RGB, CMYK, Pantone | |
| Typography specification | |
| Brand guidelines document | |
| File ownership (not license) | |

If more than 3 of these are missing or unclear, the package is incomplete. Ask for them to be added, or factor in the cost of getting them separately.

A branding package that includes all of the above, with a professional process and clear ownership, typically costs $1,500–$4,000 from an independent studio and $3,000–$8,000 from a full agency.
