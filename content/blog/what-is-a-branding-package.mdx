Most people who've been disappointed by a branding project say the same thing when you ask what went wrong.

"I didn't know what I was getting."

They paid for a "branding package." They received a PNG file and a colour code in an email. They assumed the rest was coming. It wasn't.

The problem isn't that the designer was dishonest. The problem is that "branding package" has no standard definition. One designer's branding package is another designer's logo-only project with a different label. You need to know exactly what you're buying before you commit.

Here's what a complete branding package actually contains — and how to check whether you're getting it.

---

## What Every Branding Package Must Include

These are the things that make a branding package a complete, usable brand delivery. If any of them are missing, you don't have a complete package — regardless of what the proposal says.

### Logo Files in Every Format You'll Need

The logo itself is one thing. But a logo file is not one file.

A complete logo delivery is a folder of files, each one serving a different purpose. Here's what should be in it:

**The AI source file** (Adobe Illustrator). This is the original, editable file. It's what a future designer would open to make changes, create variations, or adapt the logo for new uses. Without this file, you don't truly own your logo — you own an exported copy of it.

**EPS.** An older vector format that works in professional print production workflows. Printers, sign makers, embroidery suppliers, and screen printers often request EPS. Even if you never open it yourself, you'll be asked for it.

**SVG.** A vector format that web browsers read natively. Your website developer will need this. It's infinitely scalable at zero file size cost — important for performance and for retina screen displays.

**Print-ready PDF.** Clean vector data in a universally readable format. Printers love it. New employees sharing your logo in a presentation can use it. Suppliers who don't have Adobe software can open it.

**PNG with transparent background.** Your most-used daily file. Transparent background means the logo can sit on any colour surface without a white box around it. You need this for your website, email signatures, social media profiles, and anywhere the logo goes over a non-white background. Multiple sizes — small for web, large for high-resolution digital use.

**JPEG.** For documents and email attachments where file size matters and transparency isn't needed.

That's a minimum of six to eight files for the logo alone. Before colour variants.

### Logo Colour Variants

Your logo in one colour version is not a complete logo delivery.

You need at least three versions:

**Full colour.** Your primary logo on a white or light background. This is the main version.

**Reversed (white version).** Your logo in white or a light colour, for use on dark backgrounds, coloured surfaces, or photography overlays. Without this, you'll find yourself trying to use a dark logo on a dark background and wondering why it looks wrong.

**Mono (single colour black).** For embossed business cards, rubber stamps, embroidery, laser engraving, and any context where colour printing isn't available.

Each variant should exist in all the file formats above. Full colour AI, reversed AI, mono AI. Full colour PNG, reversed PNG, mono PNG. And so on.

This is a lot of files. It's supposed to be. A complete logo delivery is typically 20–40 files when you count all formats and variants.

### Colour Palette With Exact Values

"Your brand colour is navy blue" is not a colour palette.

A complete colour palette specifies exact values for every medium. Because the way colour is specified differs depending on where it's being reproduced:

**HEX** for web and digital design.
**RGB** for screen use and digital design tools.
**CMYK** for print.
**Pantone** for precision print production — packaging, brand-critical stationery, signage — where colour accuracy matters more than approximation.

If your designer gives you only a HEX code, you have a web colour. You'll have problems the moment you go to a printer who asks for CMYK values, or a packaging supplier who needs Pantone.

A complete colour palette also documents approved colour combinations — which colours work together, which ones to avoid, and what text colour works on each background. This prevents someone choosing an on-brand colour combination that still looks wrong.

### Typography Specification

Your brand fonts and how to use them.

A complete typography specification includes: what the fonts are (with the exact name so anyone can find or license them), which is used for headlines versus body text, approved font weights, and any specific typographic rules — all-caps headings, minimum sizes, line spacing preferences.

It also includes web fallback fonts — what to use when the brand font isn't available in a web context, or when someone doesn't have the font installed.

Without a typography specification, every freelancer and team member who creates something for your brand will make different font choices. Your brand will start looking like five different businesses.

### Brand Guidelines

This is what separates a professional brand delivery from a logo delivery.

Brand guidelines — also called a style guide or brand book — are the rules for using the brand consistently. They contain everything above (logo usage, colours, typography), plus:

**Logo usage rules.** Clear space around the logo — the minimum breathing room. Minimum sizes. Which variant to use on which background. And critically: what not to do. Examples of incorrect usage are often more useful than examples of correct usage.

**Do's and don'ts.** Specific visual examples showing the brand used correctly and incorrectly. These protect your brand when it's applied by people who weren't part of the original project.

**Imagery style.** If applicable — the visual approach to photography or illustration. Types of shots. Colour treatment. What the brand's visual world looks and doesn't look like.

Without guidelines, your brand will drift. Different people will use different colours. The logo will get stretched in a presentation. A supplier will use an old version. The guidelines are what prevent this — not by policing every use, but by making the right use easy to follow.

## What Better Packages Add

These elements aren't in every branding package. But they should be in any comprehensive one.

### Brand Strategy Document

Before the visual design, a strategy-first agency will produce a written brand strategy. This covers: who the brand is actually for, how it's positioned relative to competitors, what it stands for, and how it should make people feel.

This document is what makes visual decisions intentional rather than aesthetic. It's the difference between a logo that looks good and a logo that communicates the right thing to the right people.

Ask whether brand strategy is included before you start. If it isn't, find out whether the agency still does discovery work informally — or whether they're designing without knowing your business.

### Application Design

Showing how the brand looks in real contexts.

Business cards. Email signature layout. Letterhead. Social media profile assets — profile photo, cover image. A presentation template. A proposal template.

These aren't always included in a standard branding package. But they're worth asking about, because seeing the brand applied to real materials confirms that it works beyond the logo presentation. It also catches issues before the guidelines are finalised.

### File Ownership Confirmation

This one isn't a deliverable. It's a legal point that most clients forget to ask about.

When you receive your branding package, do you own the files? Or do you have a license to use them?

Most reputable agencies transfer full ownership including source files. You can use the brand however you like, modify it, share it with any future designer, license it.

Some services — particularly cheap logo platforms — retain source file ownership and license you the final logo. This means any future change requires going back to the original supplier, who may charge significant fees or may no longer exist.

Ask directly, before you start: "Will I receive the original source files, and will I own them completely?" Get the answer in writing.

## What Cheap Packages Are Usually Missing

Below a certain price point, something gets cut. Usually more than one thing.

**No source files.** The logo is delivered as PNG or JPEG only. You own an image. You don't own a logo. You won't be able to use it professionally at scale, and you'll have to start over the next time you need a change.

**No brand guidelines.** The colour code is mentioned in an email. The font name is in the invoice. Nothing is documented in a usable format. The moment someone else touches the brand, consistency is gone.

**One concept, minimal process.** One direction is presented with no discovery, no strategy, no alternatives. If it doesn't resonate, there's nothing to refine — just a reset.

**No colour variants.** Full colour only. When you need a white version for a dark background — for merchandise, for a coloured presentation slide, for an event banner — you're improvising or paying again.

**License, not ownership.** Some services retain source files and license you the logo. You're renting your own brand.

None of this is always visible from the listing or the pitch. Ask directly. Get the answers before you pay.

## How to Evaluate What You're Being Offered

When you receive a quote for a branding package, ask for a written list of exactly what's included. Not "a complete brand identity" — what files, what variants, what documents, how many concepts, how many revision rounds.

Then check it against this list:

- Vector source files (AI/EPS): included?
- SVG for web: included?
- PNG in transparent background, multiple sizes: included?
- Print-ready PDF: included?
- Full colour, reversed, and mono variants: all included?
- Colour palette with HEX, RGB, CMYK, Pantone: included?
- Typography specification: included?
- Brand guidelines document: included?
- File ownership (not license): confirmed?

If more than three of these are missing or unclear, the package is incomplete. Ask for them to be added — or factor in the cost of getting them separately after the fact. [What files a designer should deliver](/blog/what-files-should-a-designer-deliver) covers each of these in detail if you want to go deeper on any specific deliverable.

A branding package that covers all of the above, with a professional process and clear ownership, typically costs $1,500–$4,000 from a professional studio. Knowing this upfront prevents paying $800 for something that will cost $1,500 to complete properly later.
