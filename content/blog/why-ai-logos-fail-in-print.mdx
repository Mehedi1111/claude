You generated a logo in Midjourney. It looked incredible on screen. Your team loved it. You sent it to a print vendor — and the file came back corrupted, or worse, it printed with blurry edges, haloing, and colours that bore no resemblance to your brand.

This isn't a print vendor problem. It's a file problem.

<Callout type="info" title="The Core Issue">
AI image generators produce raster files. Professional print production requires vector files. These are fundamentally different formats — and one cannot substitute for the other.
</Callout>

## The Raster Problem

A raster file stores images as a fixed grid of coloured squares called pixels. When you scale a raster image beyond its native resolution, those squares become visible. This is why your Midjourney logo looks crisp on a phone screen but blurry on a billboard.

The numbers make the problem concrete:

| Format | Native Resolution | Print at 300 DPI | Result |
|--------|------------------|------------------|--------|
| AI Output (1024×1024) | 72 DPI screen | ~3.4 × 3.4 cm | Acceptable |
| AI Output (1024×1024) | 72 DPI screen | A4 letterhead | Degraded |
| AI Output (1024×1024) | 72 DPI screen | 40cm × 40cm | Unusable |

Standard AI generators produce images at roughly 72–96 DPI at their output resolution. Print production typically demands 300 DPI minimum at final print size. The mathematics don't work.

## Path Integrity and the CMYK Gap

Vector files describe shapes as mathematical equations. A circle is not 10,000 pixels — it's a centre point, a radius, and a stroke weight. Render it at any size, and the math produces a perfect curve. AI output skips this layer entirely.

The second problem is colour. Print production typically uses CMYK colour mixing, while AI tools generate RGB visuals. The conversion is not automatic, and without proper colour profile management:

Your brand's black can print purple. A saturated blue can desaturate dramatically. Skin tones in illustrations can shift orange. The CMYK gap is invisible on screen and catastrophic in print.

## The Technical Failure Points

When a print vendor rejects an AI-generated file, it's usually one of three things:

**1. Open paths.** Vector-adjacent SVG exports from some AI tools produce paths with disconnected endpoints. Press-ready PDFs require all paths to be closed.

**2. Missing bleed.** Print files require 3–5mm of bleed (artwork extending beyond the crop mark). AI tools don't know your print specifications.

**3. Incorrect resolution.** Even when a vendor accepts a raster file, the output will be wrong. They either request 300 DPI at final size, or they upscale — which blurs the image further.

<Callout type="warning" title="A Common Mistake">
Upscaling a raster image in Photoshop to 300 DPI does not improve its quality. It only increases the file size. The pixel information that was never there cannot be created retroactively.
</Callout>

## The Correct Rebuild Process

Professional vectorisation begins with studying the raster carefully — understanding the designer's intent, the geometry, the proportions. Then every shape is traced by hand using Bézier curves in a vector editor.

The process, in order:

1. **Geometry analysis** — Identify underlying shapes. Is the form based on a circle? A grid system? A golden ratio?
2. **Manual path construction** — Draw every shape using Bézier curves. No auto-trace.
3. **Anchor point optimisation** — Minimise anchor count while maintaining shape fidelity.
4. **Typography handling** — Either reconstruct letterforms as custom paths or source and correctly apply the original typeface.
5. **Colour translation** — Convert all colours to CMYK with Pantone references. Build a documented colour palette.
6. **File organisation** — Name layers, group elements logically, prepare for handoff.

## What You Should Actually Check

Before sending any AI-generated logo to production, verify:

- [ ] Is the file a vector format (SVG, AI, EPS)? Not just renamed?
- [ ] Are all paths closed?
- [ ] Is the colour space CMYK or does it have Pantone values?
- [ ] Is there a black version on a white background (and a white version for dark backgrounds)?
- [ ] Have the files been tested at print scale — not just screen scale?

If you can't check all five, you're not ready for production.
