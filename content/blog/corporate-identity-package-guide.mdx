A company received their new logo files from a designer. One AI file and one PNG.

Six months later, their print supplier couldn't use the AI file correctly, their web developer needed an SVG, their embroidery vendor needed a simplified version, and their presentation templates still used the old logo because nobody knew which file to use.

The logo design was good. The handoff was inadequate.

A corporate identity package isn't the logo — it's everything required to use the logo correctly, consistently, and across every context where the brand appears.

---

## The Logo File Set

This is the foundation. A complete logo file set covers every combination of:

**Logo variants:**
- Primary lockup (combination mark — symbol plus wordmark together)
- Stacked lockup (symbol above wordmark, for square-format contexts)
- Horizontal lockup (symbol beside wordmark, for wide-format contexts)
- Symbol only (for small contexts: app icon, embroidery, favicon)
- Wordmark only (for document headers and contexts where the symbol would compete)

**Colour versions, per variant:**
- Full colour (on light background)
- Reversed/white (on dark background)
- Single-colour black
- Single-colour Pantone (if a spot colour is specified)

**File formats:**
- Vector: AI (Adobe Illustrator source), EPS, SVG
- Raster: PNG (transparent background), high-resolution JPEG

A full combination mark logo system following this structure produces 15–25 files. If your handoff contains fewer than 10, ask for the complete set.

For a full explanation of which file goes where, see [what files should a designer deliver](/blog/what-files-should-a-designer-deliver).

## The Brand Guidelines Document

The guidelines document is the rulebook. It tells anyone creating brand materials — designers, marketers, team members, external vendors — how to use every element of the identity correctly.

A complete brand guidelines document covers:

**Brand foundation**
- Brand positioning statement (who the brand is for and what it stands for)
- Core values and how they inform visual decisions
- Brand personality and tone of voice

**Logo system**
- How to use each logo variant correctly
- Minimum size requirements (the smallest size the logo can appear and remain legible)
- Clear space rules (the minimum margin around the logo)
- What not to do (common misuses, shown explicitly)
- Approved and prohibited colour backgrounds

**Colour system**
- Primary and secondary colour palettes
- Pantone (PMS) numbers for each colour — used for print production, embroidery, signage
- CMYK breakdowns for print
- RGB and HEX codes for digital
- Colour proportions — which colours are dominant, which are accent

**Typography system**
- Primary and secondary typefaces
- Font licences and where to obtain them
- Type hierarchy specification (heading 1, heading 2, body, caption — sizes and weights)
- Type colour and contrast specifications
- Web font fallbacks

**Photography and imagery**
- Art direction: what kinds of images are on-brand
- What to avoid
- Examples of approved imagery

**Brand voice and tone**
- How the brand writes: formal or conversational, active or passive, personal or institutional
- Examples of on-brand and off-brand copy

**Application examples**
- How the identity looks applied to real materials: a business card, a letterhead, a presentation slide, a social media post
- These examples are critical — they show how all the elements work together, which the individual rules can't

See the [brand guidelines guide](/blog/brand-guidelines-what-they-include) for a deeper breakdown of what goes into each section.

## Core Application Templates

Rules without tools create inconsistency. The templates are what make the guidelines usable in practice.

A standard corporate identity package includes:

**Business card**
- Front and back design in the correct dimensions (85mm × 55mm standard, 3.5" × 2" US)
- Print-ready file (usually PDF with bleed, crop marks, and embedded fonts)
- Working file for editing team member information

**Letterhead**
- A4 and US Letter versions
- Print-ready and editable formats
- Continuation page (second page without the heavy header)

**Email signature**
- HTML version (for email clients that render HTML)
- Image version (for email clients that don't)
- Instructions for different email platforms (Outlook, Gmail, Apple Mail behave differently)

**Microsoft Office / Google Workspace templates**
- Word document template with correct fonts, margins, and footer
- PowerPoint / Google Slides presentation template with master slides for all key layouts
- These are often the highest-use deliverables in the entire package — they determine how the brand looks in every internal and client-facing document

**Social media profile images**
- Correct logo versions, properly sized for LinkedIn (400×400px), Instagram, Twitter/X, Facebook
- Cover image templates in correct dimensions

## Premium Package Additions

Depending on the scope of the engagement, a full corporate identity package may also include:

**Brand manifesto or story document**
A one-to-two page document articulating the brand's purpose, values, and what it stands for. Used for onboarding new team members, for investor presentations, and for establishing a shared language about the brand internally.

**Brand launch communication**
Templates and guidance for communicating the new brand to existing clients, partners, and team members — what to say, when, and through which channels.

**Vendor briefing documents**
Ready-to-send specification sheets for print suppliers, embroidery vendors, signage companies, and web developers — containing exactly the information each vendor needs to reproduce the brand correctly.

**Extended collateral templates**
Depending on the business: proposal template, case study document template, invoice template, brochure layout. These are typically additional scope items rather than standard inclusions.

**Brand asset portal**
For larger organisations, a web-based brand portal (using tools like Frontify, Bynder, or a custom setup) where all assets are hosted, searchable, and accessible to every team member. Replaces the shared folder system that produces version control problems.

## What to Check When You Receive a Corporate Identity Package

When a design studio delivers your package, run through this checklist before signing off:

**Logo files**
- Are all variants present (primary, stacked, horizontal, symbol only, wordmark only)?
- Is each variant available in full colour, reversed, and single-colour black?
- Are vector files included (AI or EPS, plus SVG)?
- Are PNG files provided with transparent backgrounds?
- Are the files named clearly and organised in a logical folder structure?

**Colour specifications**
- Are Pantone (PMS) numbers provided for all brand colours?
- Are CMYK, RGB, and HEX codes all specified?
- Are the colour files tested against the production output? (A colour that looks right on screen may need adjustment for print)

**Typography**
- Are the typeface names and font weights clearly specified?
- Are the licence files or purchase links provided?
- Are web font options specified?

**Guidelines document**
- Is it in a format that can be shared with vendors (PDF)?
- Does it include do/don't examples?
- Does it include application examples showing the full system in use?

**Templates**
- Do the templates use embedded or linked fonts? (Embedded is safer for sharing)
- Is the email signature tested across major email clients?
- Do the Office templates open correctly on both Mac and Windows?

If anything on this list is missing, request it before signing off. A complete handoff prevents the recurring problems that happen months later when vendors and team members are trying to use incomplete assets.

## How Long Should a Corporate Identity Package Take?

The production of a complete corporate identity package — assuming the visual identity design is already approved — typically takes two to three weeks. The guidelines document is the most time-consuming element; the file production and template creation run in parallel.

A package delivered in three days for a complex identity is almost certainly incomplete. A package that takes six weeks is either unusually complex or poorly managed.
